## Правая панель и попапы

- Слова под титлом перенесены вправо от экранной клавиатуры. При 1280×720 клавиатура целиком видна: её низ 698.5px; низ панели слов697.75px. Для остальных слов список прокручивается внутри панели.
- Кнопка вставки «Богородица» добавила `бцⷣа` в редактор; иконка словаря рядом открыла статью и не изменила текст. Ponomar используется и в редакторе, и в поле запроса словаря (проверены computed font-family и размер27px).
- «Вся статья» открывает native dialog «Богоро́дица» поверх редактора. Esc закрывает его, фокус возвращается на кнопку; URL остаётся #klaviatura, текст не изменяется.
- У исходного слова и каждого варианта SCI есть отдельные иконки словаря. Для `Бл҃гослови́` / `Бл҃гословѝ` используются существующие правила раскрытия титл; popup предлагает явно выбрать похожую статью по основе. Статья «Благослови́ти» открыта из этого списка. Первая похожая лемма не выбирается автоматически.
- Для отсутствующего запроса popup показывает «Статья не найдена»; модель проверена на реальных данных из22 140 статей. Ошибка загрузки и несколько совпадений имеют отдельные состояния.
- «Посмотреть правило» на замечании о `?` открывает только правило вопросительного знака с примером `;`, а не целый раздел. В закрытом popup сохраняется режим «С разметкой»; применение исправления тоже сохраняет его.
- Карта всех33 кодов CHECK проверена на существование точных блоков. Для SCI вместо выдуманного грамматического правила дано пояснение о словарных вариантах с текущим словом.
- Церковнославянские слова в сообщении «В словаре SCI» отображаются Ponomar; русское объяснение остаётся обычным шрифтом.
- Из панели убрана фраза «Неизвестное словарю слово — совет, а не доказанная ошибка.».
- На390px и320px горизонтального переполнения нет. Popup статьи при390px имеетширину366px иотступы12px; закрытие работает. В консоли при проверенных сценариях предупреждений и ошибок нет.
