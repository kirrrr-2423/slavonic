# Церковнославянский язык

Азбука, правила, словарь, клавиатура и проверка правописания церковнославянского языка — в браузере, на компьютере и на телефоне.

**Открыть:** адрес этого сайта на GitHub Pages — `https://<логин>.github.io/<репозиторий>/`.

## Что внутри

- Азбука: 40 букв, их названия, чтение и числовые значения.
- Надстрочные знаки, правописание, титла, цифирь, чтение и знаки препинания.
- Грамматика: склонения, местоимения, глагол и причастия, служебные слова; формы любого слова по правилам.
- Конвертер титл в обе стороны и переводчик чисел.
- Клавиатура со славянской раскладкой и проверка правописания.
- Словарь — 22 140 слов с толкованием.

## Как установить

Программа работает и без установки — достаточно открыть сайт. Установленная, она открывается в отдельном окне и работает без интернета.

- **Chrome, Edge (Windows, macOS, Linux, Android):** кнопка «Установить как программу» в меню разделов или значок установки в адресной строке.
- **iPhone, iPad (Safari):** «Поделиться» → «На экран „Домой“».
- **Safari на Mac (macOS 14 и новее):** «Файл» → «Добавить в Dock».

Новые версии подхватываются сами: когда сайт обновится, программа предложит перезагрузиться.

## Горячие клавиши

⌘ на Mac, Ctrl на Windows и Linux. В установленной программе работают все; во вкладке браузера часть из них может занимать сам браузер.

| Клавиши | Действие |
|---|---|
| ⌘1 … ⌘9 | разделы |
| ⌘K | клавиатура |
| ⌘⇧P | проверка правописания |
| ⌘D | словарь |
| ⌘F | поиск по правилам и словарю |

## Источники и лицензии

- Правила и примеры — по учебному руководству А. Г. Кравецкого и А. А. Плетнёвой.
- Словарь — по «Полному церковно-славянскому словарю» прот. Григория Дьяченко, электронная редакция «Азбуки веры». Правописание заглавных слов выверено по правилам учебника.
- Шрифт Ponomar (SIL Open Font License) загружается с Google Fonts и сохраняется для работы без интернета.
- Запасной шрифт GNU FreeSerif (GPL с исключением для шрифтов) — в папке `fonts`, вместе с текстом лицензии.
