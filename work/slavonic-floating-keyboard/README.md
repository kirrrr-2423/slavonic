# Плавающая церковнославянская клавиатура

Нативное приложение для macOS 13+ на Apple Silicon. Панель перемещается за заголовок, меняет размер, остаётся поверх обычных окон и показывается на рабочих столах Spaces. Нажатия на клавиши не активируют панель и сохраняют фокус документа.

Раскладка четырёх основных слоёв автоматически экспортируется из текущей экранной клавиатуры `outputs/slavonic-demo/keyboard.js`: позиции букв, знаков и пустых клавиш совпадают. Отдельно доступны надстрочные буквы и шесть частых знаков. Слои выбираются мышью; системная физическая раскладка не меняется.

В текстовом редакторе поставьте курсор в документ и выберите Ponomar. При первом использовании нажмите **Разрешить ввод** и включите приложение, указанное macOS в системном запросе, в настройках → Конфиденциальность и безопасность → Универсальный доступ. При встроенном запуске macOS может указать основную программу. Приложение проверяет разрешение, но не запрашивает его автоматически при запуске. На системе без разрешения знаки не отправляются.

Ввод использует Unicode-события Quartz, включая последовательности надстрочных знаков. Буфер обмена не читается и не меняется. Глобальные клавиши не перехватываются, текст из других приложений не читается. Проверка правописания остаётся в основном редакторе.

Некоторые приложения могут самостоятельно преобразовывать клавиатурные события, а защищённые поля могут не принимать программный ввод. Apple прямо указывает это ограничение Unicode-событий; совместимость с Word требует отдельной проверки на машине с предоставленным разрешением. Панель не меняет шрифт документа.

## Сборка и интеграция

`python3 work/slavonic-floating-keyboard/tools/build.py` собирает и проверяет `build/SlavonicFloatingKeyboard.app`. Сборка ARM64, подпись ad-hoc, без Developer ID и notarization. Обычный запуск приложения самостоятельный, с закрытием через красную кнопку окна.

Основная программа запускает `Contents/MacOS/SlavonicFloatingKeyboard` дочерним процессом с `--events-stdio` (синоним `--integrated`) без shell. Это добавляет кнопку **Вернуть в программу**. В stdout выводятся JSONL-события:

- `{"event":"ready","trusted":false,"dryRun":false,"bundleID":"ru.slavonic.floatingkeyboard"}` — панель уже показана; теперь можно скрыть основное окно.
- `{"event":"attach"}` — нажата кнопка возврата или закрытия; основной редактор следует показать. После этого процесс завершается.
- `{"event":"closed"}` — завершение процесса. При аварийном завершении родитель также должен восстановить основное окно.

Ресурсы определяются через Bundle.main; приложение можно перемещать внутрь родительского `.app/Contents/Helpers/`. Стабильный bundle ID — `ru.slavonic.floatingkeyboard`. Подпись и путь влияют на разрешения macOS; выдавайте разрешение окончательной установленной копии.

`--self-test` проверяет модель и Unicode без создания NSApplication, публикации событий и запроса разрешения. `--dry-run` показывает панель, но сохраняет нажатия только во временной пробной строке. При одновременном `--events-stdio` выдаёт событие `preview` с пробным текстом. Это режим проверки интерфейса; документ другого приложения не меняется.
